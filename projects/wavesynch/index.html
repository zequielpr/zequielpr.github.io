The Problem

Sharing audio is still frustrating. Bluetooth usually limits audio sharing to one or two devices, speakers disturb people around you, and internet streaming drains both data and battery. Listening together shouldn’t feel this complicated.

Our Solution

WaveSync streams compressed audio over UDP on the local network, keeping playback tightly synchronised across all devices in real time.

Connection System Design

Design Rationale
TCP
Reliable handshake before streaming

The host must know the guest's UDP port before any audio can flow. TCP's guaranteed delivery and ordering ensures this setup exchange never silently fails — a dropped or reordered message here would mean the stream never starts.

UDP
Fire-and-forget for the audio stream

A dropped audio packet produces a brief glitch; waiting for TCP to retransmit it would cause a far more jarring stutter — and arrive too late to be useful. UDP's lack of retransmission overhead is exactly what keeps latency low and playback smooth across devices.

TCP
Guaranteed delivery for session control

Expulsion and control messages switch back to TCP because they must arrive. If a guest never receives their kick notification they would keep a buffer open and continue playing stale audio indefinitely, which would be a confusing and broken experience.

App Architecture

Model-View-ViewModel

WaveSync is built on MVVM — a pattern that cleanly separates the UI from business logic and data, making the codebase easier to test, extend, and reason about as the app grew in complexity.

🧩
Separation of concerns

Composables only describe what the user sees. ViewModels own state and audio logic. Repositories own data. Each layer has a single responsibility and is independently replaceable.

🧪
Testability

ViewModels carry no Android UI dependency, so sync logic, packet sequencing, and playback state can be fully unit tested with JUnit and Coroutine test utilities — no emulator required.

🔄
Lifecycle safety

ViewModels survive screen rotations and configuration changes, so audio streams are never torn down and re-established just because the user rotated their device.

⚡
Reactive UI with StateFlow

Compose recomposes automatically on StateFlow emissions from the ViewModel, keeping playback state, peer list, and sync indicators always consistent without manual refresh calls.
